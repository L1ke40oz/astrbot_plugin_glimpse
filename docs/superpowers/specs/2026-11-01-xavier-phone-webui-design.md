# 沈星回的手机 · 小手机前端 设计文档

日期：2026-11-01
状态：已通过审查，待用户确认
所属插件：astrbot_plugin_glimpse（同仓库，分支 feat/v0.1 之上继续开发）

## 1. 意图与动机

插件已经能把沈星回聊天里的拍照、胶片、涂鸦标记变成真图，并把每张图记进相册（`album/album.jsonl` + 图片文件）。用户希望有一个**像拿到他手机一样**的地方，翻看这些照片和涂鸦：仿 iPhone 的界面、液态玻璃质感，用自己的手机浏览器就能打开。

第一版只有三个 App：**相册**、**画板**、**设置**，以后再按需增加。

## 2. 目标

1. 插件内置一个**独立网页服务**（不使用 AstrBot WebUI 的插件 Pages），有自己的监听地址和端口，默认 `127.0.0.1:1850`。
2. **密码登录**：首次打开设置密码，之后用 cookie 保持登录。
3. **主屏**：仿 iOS 主屏，状态栏显示当前时间，App 图标采用液态玻璃风格，有底部 Dock；壁纸和主题色可在设置中更换。
4. **相册**（拍照和胶片）：
   - 缩略图网格，按时间倒序；顶部可在「全部」「收藏」和用户自建相册之间切换。
   - 点开后全屏查看，左右滑动切换。
   - 底部操作栏：收藏（♡）、添加到相册（选择已有相册或新建）、信息（ⓘ，显示他写的描述、拍摄时间、地点）、删除（二次确认后删除图片文件和记录）。
   - 胶片照片在缩略图右上角显示胶卷小图标。
   - 用户相册可以新建、改名、删除；删除相册不删除照片。
5. **画板**（涂鸦）：网格 + 全屏查看，查看器和操作栏与相册共用。
6. **设置**：更换壁纸（内置几款 + 上传自己的图片）、更换主题色（App 图标和界面强调色）、修改登录密码。
7. **适配**：用手机浏览器打开时铺满屏幕（处理刘海和底部安全区）；在电脑上打开时，页面居中显示一台竖向手机框（约 390×844）。

## 3. 非目标（第一版不做）

- 下载图片（用户可以在 QQ 里保存）。
- 在小手机里修改插件配置：两处都能修改同一份配置时容易互相覆盖，配置仍在 AstrBot 后台修改。
- 用户在画板上自己画画、修改他的涂鸦，或者“共享”给他（见第 9 节）。
- 多用户和多账号。
- 前端构建工具链（Vue/React/打包）。

## 4. 反目标

- 不登录就能看到任何照片或调用任何接口。
- 公网上的陌生人抢先设置密码，或者通过反复尝试猜中密码。
- 网页服务出错导致插件本身（生图、发消息）不能用，或者 AstrBot 启动失败。
- 删除或整理照片时破坏插件写相册记录的逻辑（例如插件正在追加记录时丢数据）。
- 能通过接口读到相册目录以外的文件。
- 界面卡顿：网格直接加载 2MB 的原图。

## 5. 约束

- AstrBot `>=4.16,<5`，Python 3.10+，Windows/macOS/Linux；遵守 AGENTS.md（KISS、`pathlib`、英文注释和日志、Google 风格 docstring、ruff）。
- 部署环境：开发在用户的 Windows 电脑上，**正式运行在云服务器上，之后会暴露到公网**，监听地址设为 `0.0.0.0`。插件本身只提供 HTTP；README 建议在前面加 Nginx/Caddy 反向代理并启用 HTTPS，并给出一个 Caddy 配置示例。
- 这个 bot 只有用户一个人在聊（见主设计文档），所以小手机显示相册里的**全部**记录，不按会话筛选。
- 后端使用 **aiohttp.web**（aiohttp 来自 AstrBot 核心依赖，不需要写进插件的 requirements.txt）；图片处理使用 Pillow（已在 requirements.txt）。不引入新的 Python 依赖。
- 前端：`webui/static/` 下的 `index.html`、`app.js`、`style.css`，原生 JavaScript（可用 ES modules），**不依赖任何 CDN**（局域网可能无外网）。
- 液态玻璃用 CSS 实现：`backdrop-filter` 模糊与饱和、半透明渐变与高光描边，可选 SVG 位移滤镜做折射。在不支持 `backdrop-filter` 的浏览器上退化为半透明纯色，界面仍可用。
- 相册数据来源是现有的 `Album`（`album.py`）：`album.jsonl` 每行包含 `kind`（photo/film/doodle）、`scene`、`description`、`created_at`、`file` 等字段，图片位于 `album/` 下。

## 6. 方案比较（已选定 A）

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A. 单页 HTML + 原生 JS，aiohttp 后端** | 三个静态文件 + 若干 JSON 接口 | 零依赖、无构建、改完刷新即生效；与 ob_memory 的做法一致 | App 多了以后需要自觉拆分 JS 文件 |
| B. Vue/React + 构建 | 组件化单页应用 | 组件组织更整齐 | 需要 Node/pnpm，每次改都要构建，并提交构建产物；现阶段功能量用不上 |
| C. AstrBot 插件 Pages | 嵌在 AstrBot WebUI 里 | 不用单独起服务 | 用户明确不要；只能在 AstrBot 后台里打开 |

用户选择 A。后端用 aiohttp 而不是 ob_memory 的 FastAPI + uvicorn，可以少管理一套服务器生命周期，也不新增依赖。

## 7. 已确定的设计

### 7.1 配置（`_conf_schema.json` 新增分组，放在最前面）

`webui_config`「小手机」：
- `enabled`（bool，默认 true）：启用小手机网页服务。
- `host`（string，options `127.0.0.1` / `0.0.0.0`，默认 `127.0.0.1`）：提示“127.0.0.1 仅本机访问；0.0.0.0 局域网其他设备也能访问”。
- `port`（int，默认 1850）。

### 7.2 生命周期

- 在插件的 `async def initialize()`（目前 main.py 还没有，需要新增）中按配置启动服务；在 `terminate()` 中停止，并保留关闭 HTTP 会话的现有逻辑。
- AstrBot 在加载插件的 try 块里 `await initialize()`，任何逃出的异常都会让**整个插件加载失败**。所以端口被占用、启动失败等错误**必须**在 `initialize()` 内部捕获，只记录错误日志，不影响插件其他功能。

### 7.3 登录

- 密码用 `hashlib.pbkdf2_hmac('sha256', …)` 加随机盐保存，存放在插件数据目录的 `webui/auth.json`。
- 登录成功后发放随机 token，放在 HttpOnly、SameSite=Lax 的 cookie 中，有效期 7 天。会话保存在内存里，AstrBot 重启后需要重新登录。
- 接口：查询状态（是否已设置密码、是否已登录）、首次设置密码、登录、登出、修改密码（需提供旧密码）。
- **首次设置密码需要一次性设置码**：尚未设置密码时，服务启动后生成一个 6 位数字设置码，并用 `logger.info` 打印到 AstrBot 日志（用户可在 AstrBot 后台的控制台看到）。设置密码时必须同时提交这个设置码；设置成功后设置码作废。这样即使在公网上，没有 AstrBot 后台权限的人也无法抢先设置密码。设置码只保存在内存里，每次重载插件时重新生成。
- **密码强度与防暴力破解**：密码至少 8 位。每次密码或设置码校验失败后固定延迟约 1 秒；10 分钟内累计失败 10 次后，暂停所有登录和设置尝试 10 分钟（全局计数，不按 IP 区分，因为套反向代理后看到的 IP 可能都相同）。
- **Cookie**：HttpOnly、SameSite=Lax；请求经由 HTTPS 时（请求本身是 HTTPS，或反向代理传来 `X-Forwarded-Proto: https`）再加上 `Secure`。
- **忘记密码**：删除插件数据目录下的 `webui/auth.json` 并重载插件，即可重新设置。README 里写明。
- 除登录相关接口和静态页面外，所有接口都要求已登录，未登录返回 401。

### 7.4 数据存储

- **相册记录**：仍以 `album.jsonl` 为准，小手机只读取它，删除时才修改。
- **整理信息**：`album/library.json`，格式为 `{"favorites": [文件名...], "albums": [{"id", "name", "files": [文件名...]}]}`，与插件写记录的逻辑完全分开。
- **缩略图**：按需生成到 `album/thumbs/`（长边约 480px 的 JPEG），首次请求时生成并缓存；原图删除时一并删除缩略图。
- **界面设置**：`webui/settings.json`，包含 `wallpaper`（内置壁纸的 id 或上传文件名）和 `accent`（主题色十六进制值）。
- **上传的壁纸**：`webui/wallpapers/`，限制 10MB，用 Pillow 校验并转为 JPEG 存储。
- **内置壁纸**：用 CSS 渐变实现（例如星空蓝、晨雾、暖杏、夜色），不需要图片资源。

### 7.5 删除照片

- 由 `Album` 新增 `delete(file)` 方法完成：删除图片文件，并把 `album.jsonl` 中对应行去掉（写入临时文件后原子替换）。
- `Album.save()` 和 `Album.delete()` 都是同步方法，并且都在 AstrBot 的事件循环上执行（aiohttp 的处理函数和插件钩子在同一个循环里），所以二者不会交错，不需要加锁。**不要**把 `delete()` 或 `save()` 放到线程里执行（例如 `asyncio.to_thread`），否则追加和重写可能交错，导致丢记录。
- 删除照片后，这张图不再计入当天的每日上限（`count_on` 统计的是剩下的记录）。每日上限默认关闭，这样处理最简单。
- 同时从 `library.json` 的收藏和所有相册中移除该文件，并删除缩略图。

### 7.6 接口（前缀 `/api`，全部返回 JSON，图片接口除外）

- 认证：`GET /api/auth/status`、`POST /api/auth/setup`、`POST /api/auth/login`、`POST /api/auth/logout`、`POST /api/auth/password`。
- 照片：`GET /api/photos?app=album|doodle&view=all|favorites|<相册id>`，返回按时间倒序的列表，每项包含 `file`、`kind`、`scene`、`description`、`created_at`、`favorite`、`albums`。`app=album` 包含 photo 和 film；`app=doodle` 只包含 doodle。
- 图片：`GET /api/image/{file}?thumb=1`。`file` 必须是 `album.jsonl` 中存在的文件名，否则返回 404，防止路径穿越。
- 收藏：`POST /api/photos/{file}/favorite`，请求体 `{"value": true|false}`。
- 删除：`DELETE /api/photos/{file}`。
- 相册：`GET /api/albums`、`POST /api/albums`（新建）、`PATCH /api/albums/{id}`（改名）、`DELETE /api/albums/{id}`、`POST /api/albums/{id}/photos`（请求体 `{"file", "add": true|false}`）。
- 设置：`GET /api/settings`、`POST /api/settings`、`POST /api/wallpaper`（multipart 上传）、`GET /api/wallpaper/{name}`。
- 静态页面：`GET /` 返回 `index.html`，`/static/*` 返回静态资源。

### 7.7 前端交互

- **登录页**：未设置密码时显示“设置密码”，需要填写设置码和两次新密码，并提示“设置码在 AstrBot 控制台日志里”；否则显示“输入密码”。暂停登录期间显示剩余等待时间。登录页统一使用默认的内置渐变壁纸，因为用户上传的壁纸可能是私人照片，必须登录后才能获取。
- **主屏**：状态栏（时间，以及装饰性的信号和电量图标）、App 网格（相册、画板、设置）、底部 Dock 放同样三个 App。点击图标时，App 从图标位置放大打开；从底部上滑或点左上角返回，回到主屏。
- **相册 App**：顶部分段控件切换「全部 / 收藏 / 相册」；选择「相册」时先显示相册列表（可新建、改名、删除），再进入相册的网格。
- **查看器**：全屏黑底，支持左右滑动和键盘左右键；单击切换操作栏的显示和隐藏；信息面板为底部液态玻璃抽屉，显示描述、拍摄时间（如 `2026年11月1日 02:18`）和地点（场景名；为空时不显示这一行）。
- **画板 App**：与相册相同，但没有胶卷角标；顶部分段为「全部 / 收藏」（是否提供「添加到相册」由实现者决定，见第 8 节）。
- **设置 App**：iOS 风格分组列表，包含墙纸、主题色、修改密码。
- 主题色作为 CSS 变量作用于图标渐变、按钮和高亮。

## 8. 我替用户做的决定（请过目）

- 后端用 aiohttp.web，不用 Starlette + uvicorn。
- 密码哈希用 PBKDF2，比 ob_memory 的单次 SHA-256 更安全；会话只存在内存，重启后需要重新登录。
- 缩略图按需生成并缓存。
- 内置壁纸用 CSS 渐变，不放图片资源。
- 收藏、自建相册、界面设置存在独立的 JSON 文件里，不改动 `album.jsonl` 的格式。
- 画板的涂鸦也可以收藏和删除；“添加到相册”是否对涂鸦开放由实现者决定，默认不开放，相册只装照片。
- 小手机服务默认启用，但默认只监听 `127.0.0.1`。
- 首次设置密码需要 AstrBot 日志里的一次性设置码；忘记密码时删除 `webui/auth.json` 并重载插件。
- 防暴力破解：10 分钟内失败 10 次后暂停登录 10 分钟；密码至少 8 位。
- 登录页使用默认壁纸。
- 删除的照片不再计入每日上限。
- 显示全部会话的照片，不按会话筛选。
